# StyleMatchIA

## Descripcion de la app

StyleMatchIA es una aplicacion Android relacionada con la moda. 
La idea principal es que el usuario pueda ver un catalogo de ropa y encontrar prendas que encajen con su estilo, 
sus gustos o lo que necesita en un momento concreto. Ademas, la app no solo muestra productos, 
sino que tambien intenta ayudar al usuario con recomendaciones.

## Funcionamiento

Cuando el usuario entra en la aplicacion, primero puede iniciar sesion o registrarse. 
Despues accede al catalogo principal, donde puede ver distintos productos, buscarlos por texto 
y filtrarlos por categorias.

Cada producto tiene su propia pantalla de detalle, donde se muestra mejor la informacion, 
la imagen y el enlace de la tienda. El usuario tambien puede guardar productos 
en favoritos para tenerlos mas localizados.

La app incluye una parte de inteligencia artificial donde el usuario escribe lo que busca, 
por ejemplo una prenda, un color o un presupuesto, 
y a partir de eso se le recomiendan productos del catalogo.

Tambien hay una seccion para que el usuario envie sugerencias o recomendaciones. 
Por otro lado, existe una parte de administrador desde la que se pueden añadir, editar 
y borrar productos, ademas de revisar las recomendaciones enviadas por los usuarios.

## Tecnologias usadas

- Java
- XML
- Firebase
- Room
- OpenRouter
- ImgBB
